📦 Put it on a USB (mobile + PC)

This whole toolkit is a single file — index.html. There is no install and no server.

  1. Copy index.html to the root of your USB stick.
  2. PC/Mac/Linux: plug in, double-click index.html → opens in your browser.
  3. Android: plug USB via OTG, open the Files app, tap index.html, “Open with” a browser.
  4. iPhone/iPad: use a Lightning/USB-C reader, open Files, tap the file (Safari). Note: the shredder's in-place overwrite is desktop/Android-Chrome only on iOS.
✅ Fully offline. Turn on Airplane Mode and everything still works — all processing happens in your browser's memory. No analytics, no fonts, no CDN, no network calls.

🔬 How each tool works & its honest limits

Metadata Viewer
Parses the file's bytes directly in JavaScript: JPEG APP1/EXIF (TIFF IFD0, Exif SubIFD, GPS IFD), XMP, IPTC/Photoshop (APP13), plus PNG text chunks. It highlights privacy-sensitive fields like GPS location, device serial numbers, and timestamps. HEIC metadata support depends on your browser being able to decode HEIC.
Metadata Eraser
Lossless mode rebuilds a JPEG/PNG keeping the exact original image data but dropping the metadata segments (EXIF/XMP/IPTC/comments) — no quality loss. Re-encode mode paints the pixels onto a canvas and exports a fresh image; this guarantees zero leftover metadata for any format the browser can open, at the cost of re-compressing. Always re-open the cleaned file in the Viewer to confirm it's empty.
Secure Shredder — and why flash media is tricky
Uses the File System Access API to open a real file handle and overwrite its bytes in place with multiple passes, then truncates it to zero so you can delete an empty shell. Important limitation: USB flash drives and SSDs use wear-levelling, so the controller may write your “overwrite” to different physical cells and leave the original data intact in cells you can't address from software. Overwriting still helps, but the only reliable protection on flash is full-disk / hardware encryption (e.g. BitLocker To Go, VeraCrypt, LUKS) so any leftover fragments are ciphertext. On classic spinning hard drives, multi-pass overwrite is genuinely effective.
No warranty. For high-stakes data, combine this with full-disk encryption and, for maximum assurance, physical destruction of the media.
