⚠️ How this bin works. Files you add stay in a list. Empty Bin overwrites each file's bytes in place with multiple passes, then blanks it to 0 bytes so you can delete an empty shell — this is permanent, there is no undo. Requires Chrome / Edge (desktop or Android); the “Add files” button works everywhere those run. Heads-up: on USB sticks & SSDs, wiping isn't 100% guaranteed — the drive can secretly keep an extra copy. Encrypt the whole drive for real protection.
This browser can't overwrite files. The File System Access API isn't available here (common on iOS Safari & Firefox). Use Chrome/Edge, or your OS tools: shred -u file (Linux), Files app delete + empty “Recently Deleted” (iOS). Then encrypt the drive so leftovers are unreadable.
